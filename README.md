# BugInsight

**BugInsight** is a real-time, smart issue and bug tracking platform built with **NestJS microservices** and **React/Next.js frontend** in an **Nx monorepo**.  

## Features

- Multi-project bug tracking
- Project/folder hierarchy management
- Real-time notifications with WebSockets
- Analytics dashboards and metrics
- Modular microservices architecture
- TypeScript-first fullstack

## Tech Stack

- **Backend:** NestJS (microservices), Prisma ORM
- **Frontend:** React or Next.js
- **Monorepo:** Nx
- **Database:** PostgreSQL (or your choice)
- **Realtime:** WebSockets (via NestJS Gateway or Notification Service)
- **Shared Code:** Nx libraries for DTOs, types, and utilities
